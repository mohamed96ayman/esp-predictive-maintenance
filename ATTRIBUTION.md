# Dataset attribution

Dataset: SPE Ecuador Section, **E-challenge – Prediction Models for Historical Data of ESP Patterns** (2021).

Source: https://gitlab.com/spe.ec/e-challenge-prediction-models-for-historical-data-of-esp-patterns

The source project identifies its materials as CC BY-NC-SA 4.0, for academic purposes. Obtain the data from the source and respect its terms. This repository does not redistribute the telemetry dataset. The included trained model, learned normalization statistics, and aggregate evaluation evidence are derived from that academic study.

The project is independent and is not affiliated with SPE. Regression hierarchy values and the classifier's primary operating point are attributed to thesis v40, Tables 4.14 and 4.18, with the detailed weak-well analysis from Table 5.2. The thesis document itself is not included.
